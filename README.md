# SmileBrilL

Premium AI automation consultancy website built with Next.js, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Edit content

- Site copy, services, FAQ, contact placeholders: `src/data/site.ts`
- Portfolio projects: `src/data/projects.ts`
- Logo / favicon: `public/logo.jpg` (also copied to `src/app/icon.jpg`)

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
